# HERODES LUGO — BRANDED PORTFOLIO V2
### Editorial Agency-Grade Aesthetic // Brutalist Performance

A high-fidelity digital presence built for the modern web. This portfolio merges strict brutalist editorial design with high-performance 3D background systems and procedural motion.

---

## ── VISUAL ARCHITECTURE

The application follows a **Strict Editorial / High-Contrast** aesthetic:
- **Color Palette:** Primary Crème Nube (`#F5F5F5`) with Deep Surface overrides (`#131414`) for immersive sections.
- **Typography:** Swiss-inspired layout using high-weight tracking and semantic hierarchy.
- **Motion System:** 
  - **QuantumCloud:** A procedural celestial star shower built in Three.js with additive blending and UnrealBloom post-processing.
  - **Cyberpunk Hero:** Infinite glitch loop logic using CSS pseudo-elements and `clip-path` snapshots.
  - **CodeTerminal:** A custom VS-Code style typing engine for philosophy storytelling.

## ── TECH STACK

- **Framework:** [Next.js](https://nextjs.org/) (App Router / React Selective Hydration)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) (Themed architecture)
- **3D Engine:** [Three.js](https://threejs.org/) + React Hooks Integration
- **State Management:** [Zustand](https://github.com/pmndrs/zustand) with Session Persistence
- **Animations:** [GSAP](https://gsap.com/) (Scroll-driven choreography) & Native CSS Keyframes
- **i18n:** [next-intl](https://next-intl-docs.vercel.app/) (Strategic multilingual support)

## ── KEY FEATURES

- **[01] Session-Aware Intro:** A premium reveal sequence that locks scrolling until the animation completes, persisted via `sessionStorage`.
- **[02] Editorial Projects:** An interactive accordion-based project gallery that prioritizes content visibility and typography.
- **[03] Star Shower Background:** A GPU-accelerated particle system with vertical parallax drift and twinkling shaders.
- **[04] Responsive Fidelity:** Optimized for high-DPI displays with fluid scaling and clamped typography.

## ── GETTING STARTED

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the installation.
